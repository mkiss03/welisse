# Alex 3D Avatar Models

## Required Files:

### Avatar Model
- `alex-avatar.glb` - Ready Player Me avatar (download from https://readyplayer.me/avatar)

### Animations (Mixamo)
- `animations/idle.glb` - Standing Idle animation
- `animations/talking.glb` - Talking animation  
- `animations/waving.glb` - Waving animation

## Instructions:

1. **Download Avatar**: Go to https://readyplayer.me/avatar
   - Customize: Male, short hair, business casual, friendly face
   - Download as GLB format
   - Save as `alex-avatar.glb`

2. **Download Animations**: Go to https://www.mixamo.com
   - Search and download: "Standing Idle", "Talking", "Waving"
   - Format: FBX, 30 FPS, Without Skin
   - Convert FBX to GLB: https://products.aspose.app/3d/conversion/fbx-to-glb
   - Save in `animations/` folder

3. **File Sizes**: Keep each GLB file under 5MB for optimal loading
